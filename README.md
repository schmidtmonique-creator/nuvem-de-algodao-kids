# 🧸 Nuvem de Algodão Kids - Loja Virtual Infantil

Este é um projeto completo e funcional de **demonstração de e-commerce infantil**, desenvolvido com HTML5, CSS3 e JavaScript (Vanilla), pronto para ser hospedado no **GitHub Pages**.

---

## 🚀 Funcionalidades

- **Catálogo Interativo:** 12 produtos fictícios cadastrados com fotos, tamanhos, cores e preços promocionais.
- **Pesquisa e Filtros:** Busca dinâmica por palavra-chave, categorias, gênero e ordenação por preço.
- **Carrinho de Compras (Local):** Adição/remoção de itens e atualização automática via `localStorage`.
- **Lista de Favoritos:** Sistema de curtir produtos persistido via `localStorage`.
- **Checkout Demonstrativo:** Simulação de fechamento de pedido sem transações reais.
- **Painel Administrativo Demo:** Visualização simulada de métricas e vendas.
- **Design Responsivo:** Totalmente adaptado para Mobile, Tablet e Desktop.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** (Estrutura semântica)
- **CSS3** (Estilização responsiva com Flexbox/Grid)
- **JavaScript ES6** (Lógica do cliente e persistência em `localStorage`)
